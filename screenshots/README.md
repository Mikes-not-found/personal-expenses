# Screenshots

Genera gli screenshot con Remotion:

```bash
cd ../video
npm install
npm run screenshot
```

Questo creerà:
- `overview.png` (frame 30 — tab Panoramica)
- `predictions.png` (frame 120 — tab Previsioni)
- `insights.png` (frame 220 — tab Insights)

Copia poi i file da `video/out/` in questa cartella.
